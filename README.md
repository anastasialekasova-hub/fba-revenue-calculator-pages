# FBA Revenue Calculator — pages

Welcome, uninstall and feedback pages for the FBA Revenue Calculator Chrome extension, served via GitHub Pages.

- `/welcome/` — opens once after installation
- `/uninstall/` — short survey, opens when the extension is removed
- `/feedback/` — opens from the rating prompt for 1–3 stars

Privacy policy: https://pinwisp.com/fba-revenue-calculator/privacy/
